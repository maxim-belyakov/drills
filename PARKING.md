- **`push` returns the new length, not the array.** `acc[k] = (acc[k] ?? []).push(x)` quietly stores a number. Same family: `sort`/`reverse`/`splice` return the array itself (mutated), `map`/`filter`/`slice`/`concat` return a new one. Know what each hands back before chaining onto it. (2026-08-26, assembly A2)
- **Every plain-object key is a string.** `obj[null]` becomes the key `"null"`, `obj[1]` becomes `"1"`, `obj[{}]` becomes `"[object Object]"`. Nothing throws. A `null` field folded into a counter object creates a phantom entry that can outrank real ones. `Map` keeps key types as they are - that is the difference that matters. (2026-08-26, assembly A2)
- **When the error message does not match your understanding, suspect the spelling first.** `localCompare` for `localeCompare`, a missing `.` before `sort`. Both read as "this concept does not work" and both cost most of a session. (2026-08-26)
- **What follows `await` is a MICROtask, not a macrotask.** `await` is sugar over `.then`, so the continuation is queued exactly like a `.then` callback and runs before any timer, even a timer scheduled earlier. Only timers, intervals and I/O are macrotasks. Sighted 2026-08-28, where the wrong mechanism happened to give the right order because the snippet had no timers.
